BANANA 3D - BLENDER

Files:
- banana_3d.obj: 3D mesh, importable into Blender
- banana_3d.mtl: material definition
- banana_skin.png: yellow banana texture
- setup_banana_in_blender.py: optional Blender setup script

How to use:
1. Extract all files into one folder.
2. In Blender choose File > Import > Wavefront (.obj).
3. Select banana_3d.obj and import.
4. If texture is missing, open Shading workspace and reconnect banana_skin.png to the Principled BSDF Base Color.
5. For automatic camera and lighting, open the Scripting workspace, open setup_banana_in_blender.py, and click Run Script.

Note: This is a new procedural 3D model inspired by the uploaded reference, not a direct conversion of the flat photograph. You can edit its mesh in Blender.
