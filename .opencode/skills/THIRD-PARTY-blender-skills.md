# Third-Party Blender Skills

Source: https://github.com/arjun988/blender-skills
Version: 1.3.0 (repository main, cloned 2026-11-22)
License: MIT — see `BLENDER-SKILLS-LICENSE.txt`

The following skill folders are installed for NutriPick asset production:

`animation`, `asset-optimization`, `blender-director`, `blender-modeler`,
`character-archetypes`, `character-artist`, `environment-artist`, `export-pipeline`,
`lighting`, `lookdev`, `lowpoly-style`, `materials`, `prop-artist`, `qa-review`,
`rigging`, `scene-assembly`, `set-dressing`, `stylized-style`, `unity-export`,
plus the shared `references/` folder.
